# MyVPN

Личный VPN-клиент для iPhone.

## Сборка

GitHub → **Actions** → **iOS unsigned IPA** → **Run workflow**.
Готовый файл `MyVPN-<версия>-b<номер>.ipa` появляется в разделе **Artifacts** сборки.
Подписывается личным сертификатом и ставится через Feather / ESign / GBox.

Все изменения внешнего вида и настроек вносятся при сборке скриптом `rebrand.sh`
(перевод — `ru_extra.json`), поэтому исходный код остаётся как в основе и обновляется кнопкой **Sync fork**.
